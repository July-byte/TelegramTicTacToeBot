# Telegram Tic-Tac-Toe Bot (C# / .NET)
Телеграм- бот для игры в "крестики-нолики", разработанный на C# с использованием Telegram Bot API.
Проект реализует асинхронную обработку обновлений, работу с Inline-кнопками и хранение состояния игры для каждого пользователя.

---

## Цель проекта
Разработать Telegram-бота, демонстрирующего:
- работу с внешним API (Telegram Bot API)
- асинхронное программирование (async/await)
- обработку событий (polling)
- управление состоянием пользователей
- реализацию игровой логики

---

## Реализованный функционал
- команда /start
- запуск игры через /play
- игровое поле 3х3 с использованием InlineKeyboard
- хранение состояния игры для каждого пользователя
- ход игрока (Х)
- ход бота (О)
- проверка победы
- обработка ничьи
- завершение игры и очистка состояния

---

## Используемые технологии
- C#
- .NET 8
- Telegram.Bot
- Асинхронное программирование
- Коллекции (Dictionary)
- Работа с CallbackQuery
- Игровая логика

## Арихитектура
TelegramTicTacToeBot/
|
|-Program.cs // логика бота
|-Game.cs // игровая логика

## Принципы:
- разделение логики бота и игровой модели
- хранение состояния через Dictionary<long, Game>
- обработка событий через polling
- использование InlineKeyboard для интерактивного UI

---

## Как запустить
1. Создать бота через @BotFather
2. Получить токен
3. Вставить токен в Program.cs
4. Установить пакет Telegram.Bot
5. Запустить проект
